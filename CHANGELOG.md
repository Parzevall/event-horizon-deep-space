# Changelog

## 1.0.0

First public release.

- **Event Horizon Deep Space** color theme: true black, accretion-orange accent, and the Mission Phosphor syntax palette
  (amber keywords, green strings, teal functions, copper types) with bold italic keywords and bold definitions.
- **Event Horizon Nerd** and **Event Horizon Tiles** file icon themes.
- **Event Horizon Hull** product icon theme: 24 chamfered line icons for the activity bar, explorer toolbar and status bar.
- Editor features: comment-tag pills, inline problems with tinted error lines, folded-line counts, current-line
  git blame, trailing whitespace, optional tinted indent columns.
- `Event Horizon: Apply Setup` / `Revert Setup`, and optional custom CSS for hull markings and a macOS-style title bar.
